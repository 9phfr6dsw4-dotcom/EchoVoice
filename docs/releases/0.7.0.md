# EchoVoice 0.7.0

Breeze TTS 2 (8-bit) is back as the only voice model, for personal, non-commercial use. The model chooser has been removed.

- Existing voices, scripts, settings and recordings carry over. Complete previous 8-bit Breeze downloads are reused.
- Breeze needs the exact words from each reference clip. Add a transcript in Voices if a clip saved for Chatterbox has none.
- Old Qwen and Chatterbox audio still plays. Same Take and New Take now use Breeze and will sound different.
- Settings can open the model downloads folder. The README includes the exact Qwen, Chatterbox and tokenizer folders to move to the Trash to reclaim space; they are not deleted automatically.
- Automatic updates remain available.
