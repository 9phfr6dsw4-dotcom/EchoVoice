# EchoVoice 0.8.0

- **Delivery style is back.** Add an optional direction such as happy, angry, calm or upbeat on Generate. Breeze uses it with your saved reference voice. Adding a style takes about twice as long to generate.
- **Your style stays with each take.** Same Take, New Take and Use Script restore the saved direction. New Script clears the script and style; Undo brings both back. Older libraries with or without a saved style still load.
- **Developer ID signing and Apple notarization.** EchoVoice is signed with a Developer ID certificate, uses the hardened runtime with microphone access, and is released only after Apple accepts its notarization.

## Install

EchoVoice receives this as an automatic update. You can also choose **EchoVoice → Check for Updates…**.

macOS may ask you to allow the microphone once more after this update because the signing certificate is changing. Choose **Allow** when recording a voice. Your voices, recordings, settings and model downloads carry over.

For a first install, unzip `EchoVoice.zip`, drag EchoVoice into Applications and open it. macOS may ask whether to open an app downloaded from the internet; choose **Open**.
